# سجل طريق الحديد — النسخة المحسّنة

هذه نسخة مستقلة ومحسّنة من اللعبة القصصية الأصلية. تحتفظ بقاعدة بيانات الحملة والموسيقى والواجهة ذات الطابع القوطي، لكنها تضيف **محرك لعب محليًا موثوقًا** يتيح استمرار القصة حتى عند عدم توافر مفتاح خدمة السرد السحابية أو انقطاع الاتصال.

> **مسار المشروع:** `/home/ubuntu/iron_path_reforged`  
> **نقطة التشغيل:** `app.py`

## التشغيل

استخدم بيئة بايثون 3.11 أو أحدث، ثم ثبّت الاعتمادات وشغّل التطبيق من جذر المشروع:

```bash
cd /home/ubuntu/iron_path_reforged
pip install -r requirements.txt
python3 app.py
```

بعدها افتح المتصفح على `http://127.0.0.1:5000`.

## ما الذي تحسّن؟

| المجال | التحسين المُنفّذ | الأثر في اللعب |
|---|---|---|
| الاستمرارية | أُضيف `offline_engine.py` كمحرك سرد محلي. | تظل اللعبة قابلة للعب دون أي مفتاح API أو اتصال خارجي. |
| فهم القرارات | يصنف المحرك أفعال الاستكشاف والتفاوض والقتال والتجارة والراحة والمكيدة بالعربية والإنجليزية. | ينتج عن القرار نتيجة ذات صلة، بدل رد عام متكرر. |
| التقدم | تُحدّث الخبرة والسمات والفصائل والمرافقون والمهام والأملاك والحقيبة والخريطة وسجل القتال عبر طبقة الحالة الموجودة. | القرارات تترك أثرًا قابلًا للمراجعة في القاعة. |
| الواجهة | عُرّبت شاشة الدخول، مؤشرات الدور، أزرار التحكم، التعليمات، وحقل القرار، مع إضافة خط مناسب للعربية. | بداية لعب أوضح وتجربة عربية متماسكة. |
| المتانة | أُضيف التحقق من المدخلات، ورسائل خطأ مفهومة، وواجهة صحة `/health`، وتحقق قاعدة البيانات قبل التسليم. | تشخيص أسهل وتقليل الأعطال الصامتة. |
| الحماية | بقي المشروع الجديد في مجلد مستقل، ولم تُعدّل ملفات المشروع المرفق الأصلية. | يمكن مقارنة النسختين أو الرجوع للأصل بأمان. |
| الأطلس | أُضيف أطلس ألدينمير مع 9 أقاليم و56 موقعًا وطبقات استكشاف وLore قابل للتمدد. | تتصل الجغرافيا والسياسة والتاريخ مباشرة بخيارات اللاعب. |
| الأصول الثنائية الأبعاد | أُضيفت بورتريهات للقادة الرئيسيين ورسومات للقلاع والحصون الاستراتيجية. | تظهر الشخصيات والمواقع الرئيسة بصورة أوضح داخل أطلس الحملة. |
| الاقتصاد | أُضيفت محفظة بالنحاس ودفتر قيود وسوق سلع ذري. | تُسجَّل كل عملية شراء أو بيع أو مكافأة ولا يمكن إنفاق ما ليس في الرصيد. |

## أمثلة لقرارات اللاعب

اكتب قرارًا محددًا في حقل الإدخال، مثل:

```text
أستكشف الرصيف بحثًا عن علامة الشمع الأسود
أتفاوض مع تجار الرماد للحصول على خبر عن الرسالة
أؤمّن المعسكر وأرتاح قبل التحرك
أهاجم سرايا الملح في ممر الرماد
أبيع البضاعة في السوق وأستثمر الربح في الدار
```

يمكن أيضًا استخدام أوامر الواجهة الأصلية مثل `/recap` للملخص، و`/history` لسجل المشاهد، و`/help` لعرض المساعدة.

## بنية النسخة

| الملف أو المجلد | الغرض |
|---|---|
| `app.py` | خادم Flask المنظم ومسارات الواجهة وواجهات الحالة. |
| `offline_engine.py` | السرد المحلي وقواعد تصنيف الأفعال وتوليد العواقب. |
| `state_manager.py` | التحقق من تغييرات الحالة وتطبيقها بصورة متسقة. |
| `database.py` | مخطط SQLite وسجل الحملة والأنظمة الفرعية. |
| `templates/index.html` | الواجهة المرئية المعربة للعبة، بما فيها الأطلس والقاعة والسوق. |
| `static/assets/` | خريطة ألدينمير وبورتريهات القادة ورسومات القلاع والحصون الثنائية الأبعاد. |
| `ECONOMY_LEDGER_GUIDE_AR.md` | قواعد العملات ودفتر القيود والتجارة وكيفية توسعتها. |
| `test_economy.py` | اختبار رصيد المحفظة، منع السحب فوق المتاح، وتسوية صفقات السوق. |
| `static/medieval_song.wav` | الموسيقى المحيطة التي كانت مرفقة مع المشروع. |
| `data/story.db` | نسخة تشغيلية من بيانات الحملة الأصلية. |

## ملاحظات اختبار الجودة

أُجري فحص صياغة لملفات بايثون، وفحص سلامة SQLite، واختبار واجهة الحالة، واختبار دور استكشاف عبر الواجهة البرمجية والمتصفح. كما تم اختبار دفتر القيود بصورة معزولة، والتحقق بصريًا من عملية شراء تنعكس في الرصيد ومخزون التاجر وجرد اللاعب وسجل القيود دفعة واحدة، ثم أُعيدت قاعدة بيانات الحملة إلى حالتها النظيفة قبل التسليم.

## تحسينات مستقبلية مقترحة

يمكن إضافة نظام **حفظات متعددة**، ومحرر شخصية قبل بداية الحملة، وشجرة مهام بصريّة، وتوازن أعمق للمعارك، وترجمة بقية تبويبات القاعة. كما يمكن لاحقًا إعادة توصيل محرّك سرد سحابي اختياري، مع إبقاء المحرك المحلي بديلًا تلقائيًا حتى لا تتأثر قابلية اللعب.
